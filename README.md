# 나비텍스트 (nabitext)

글을 **쓰고, 다듬고, 꾸미고, 내보내는** 것을 한 화면에서 하는 웹 편집기입니다.
설치나 빌드가 필요 없고, `index.html`을 브라우저로 열면 바로 쓸 수 있어요.

기존 도구(iA Writer, Ulysses, Typora, Notion, Hemingway, Canva, 네이버 스마트에디터, 브런치)를
조사하고 분석한 내용은 [RESEARCH.md](RESEARCH.md)에 정리했습니다.

## 주요 기능

| 영역 | 기능 |
|---|---|
| **쓰기** | 블록 편집기 · `/` 슬래시 메뉴(한글 검색) · 마크다운 단축 입력 · 선택하면 뜨는 서식 툴바 · `Alt+↑/↓` 문단 이동 · 이미지 붙여넣기/끌어놓기 |
| **디자인** | 테마 8종(클린·에세이·매거진·뉴스레터·노트·레트로·편지·다크) · 한글 웹폰트 11종 · 글자 크기/행간/자간/문단 간격/본문 폭 · 양쪽 정렬 · 강조색 · 드롭캡 · 첫 줄 들여쓰기 · 어절 단위 줄바꿈(`keep-all`) |
| **다듬기** | 연속 공백, 전각 공백, 문장부호 앞뒤 띄어쓰기, 말줄임표 통일, 둥근 따옴표, 반복 문장부호, 괄호 안 공백, 빈 문단 — 규칙별로 몇 곳을 고칠지 먼저 보여 줌 |
| **점검** | 글자 수(공백 포함/제외) · 원고지 매수 · 읽는 시간 · 70자/100자 넘는 긴 문장 표시 · 번역투·군더더기 표현 13종 · 반복 낱말 — 클릭하면 본문에서 위치를 찾아 줌 |
| **몰입** | 포커스 모드(지금 쓰는 문단만 선명하게, 커서 줄을 화면 가운데로) · 미리보기 모드 · 밝은/어두운 화면 |
| **글 이미지** | 배경 이미지 올리기(꽉 채우기/폭 맞춤/전체 보이기/반복, 끌어서 위치, 휠로 확대, 흐림·밝기·흑백·덮는 색) · 배경 이미지 비율대로 페이지 만들기 · **글 상자를 여러 개 그려서 배치**(글이 1→2→3 순서로 흘러 넘어감, 상자마다 배경 없음/색 채움·투명도·테두리·둥글기·여백·그림자·글자색, 구분선에서 다음 상자로 넘기기) · **문단 사이에 이미지 넣기**(폭·정렬·여백, 페이지 폭 전체) · 자유 배치 꾸밈 이미지(흰 배경 지우기, 색 입히기, 대칭 복제) · 틀·모눈·종이 질감 · 한 장 또는 일정 길이로 나누기 · PNG 저장 |
| **카드뉴스** | 구분선 기준으로 카드 자동 분할 · 1:1 / 4:5 / 9:16 · 배경(테마/강조색/그라데이션/종이) · 글자 크기 자동 맞춤 · 1080px PNG 저장 |
| **내보내기** | 서식 포함 복사(블로그·메일에 붙여넣기용 인라인 스타일) · HTML · Markdown · TXT · PDF 인쇄 · `.md/.txt/.html` 불러오기 |
| **저장** | 브라우저에 자동 저장, 여러 문서 관리 |

## 사이트 주소

**https://tmzkdlleaf-bit.github.io/nabitext/** (GitHub Pages)

처음 한 번만 저장소 **Settings → Pages**에서 *Build and deployment*의 Source를 **Deploy from a branch**로,
Branch를 **claude/loving-goldberg-i2hquj**, 폴더를 **/ (root)**로 고르고 Save를 누르면 1~2분 뒤 열립니다.
이후에는 이 브랜치에 푸시할 때마다 사이트가 자동으로 갱신됩니다.

## 실행

```bash
# 그냥 파일을 열어도 되고
open index.html

# 로컬 서버로 띄워도 됩니다
npx http-server -c-1 .
```

웹폰트(Pretendard, Google Fonts)는 인터넷에서 불러옵니다. 오프라인이면 시스템 글꼴로 표시돼요.

## 단축키

| 키 | 동작 |
|---|---|
| `/` | 블록 넣기 메뉴 |
| `# ` `## ` `### ` | 제목 1·2·3 |
| `> ` / `" ` / `! ` | 인용 / 강조 인용 / 콜아웃 |
| `- ` `1. ` | 글머리 / 번호 목록 |
| `---` + Enter | 구분선(카드 나누기) |
| ```` ``` ```` + Enter | 코드 블록 |
| `Ctrl+B` `Ctrl+I` `Ctrl+U` | 굵게 · 기울임 · 밑줄 |
| `Ctrl+Shift+H` | 형광펜 |
| `Ctrl+K` | 링크 |
| `Ctrl+Alt+1~3`, `Ctrl+Alt+0` | 제목 1~3, 본문 |
| `Alt+↑` `Alt+↓` | 문단 위/아래로 옮기기 |
| `Ctrl+Z` `Ctrl+Shift+Z` | 실행 취소 · 다시 실행 |
| `Ctrl+.` | 포커스 모드 |
| `Ctrl+S` | 지금 저장 |
| `Ctrl+Shift+O` | 문서 목록 |

(macOS에서는 `Ctrl` 대신 `⌘`)

## 구조

```
index.html          화면 뼈대
css/app.css         도구 UI 스타일 (밝은/어두운 테마, 인쇄)
js/doc-style.js     글 자체의 스타일 — 편집 화면·HTML 내보내기·카드뉴스가 공유
js/themes.js        테마 프리셋, 글꼴 목록
js/editor.js        블록 편집기, 슬래시 메뉴, 서식 툴바, 붙여넣기
js/history.js       실행 취소 기록
js/tidy.js          다듬기 규칙, 붙여넣기 정리(sanitize)
js/analyze.js       글 통계와 문장 점검 (CSS Custom Highlight API)
js/convert.js       Markdown/HTML/텍스트 변환, 서식 포함 복사
js/design.js        디자인 패널
js/cards.js         카드뉴스 조판과 PNG 내보내기
js/poster.js        글 이미지 모드: 템플릿, 쪽 나누기, 장식 배치, PNG 내보내기
js/poster-assets.js 장식·질감을 코드로 그리는 생성기, 이미지 색 입히기
js/dialog.js        페이지 안 대화상자 (임베드 환경용)
js/storage.js       localStorage 저장
js/app.js           앱 조립
vendor/html-to-image.js   PNG 변환 (MIT, v1.11.11)
```

## 브라우저 지원

최신 Chrome, Edge, Safari, Firefox. 본문 점검 하이라이트는 CSS Custom Highlight API를 쓰며,
지원하지 않는 브라우저에서는 목록으로만 보여 줍니다.
